Возможности

Бот делает одно: вовремя сообщает о матчах КХЛ в вашем часовом поясе. Без новостей, ставок и рекламы.

  • Расписание по запросу

    Команды /today, /tomorrow и /week показывают матчи на нужный период. Длинные списки делятся на страницы, до 10 карточек на каждой.

  • Ваш часовой пояс

    Время начала пересчитывается в пояс из справочника IANA. По умолчанию — Europe/Moscow, сменить можно командой /timezone.

  • Ежедневная сводка

    Каждый день в 10:00 по вашему местному времени — матчи подписанных команд на сегодня. Время сводки можно изменить.

  • Напоминание до матча

    Сообщение за N часов до начала игры. По умолчанию — за 2 часа, значение меняется командой /notify remind.

  • Перенос и отмена

    Если матч перенесли или отменили, придёт ровно одно уведомление. Повторы отсекает ключ идемпотентности.

  • Устойчивость

    Если источник недоступен, бот отвечает по данным из своей БД и помечает их как устаревшие.

Стек и архитектура

Четыре слоя, каждый обращается только к следующему. Данные источника попадают в бот уже проверенными pydantic-моделями.

  • Python 3.11
  • aiogram 3.x
  • SQLAlchemy 2.x
  • Alembic
  • APScheduler
  • httpx
  • pydantic 2
  • SQLite / PostgreSQL 15
  • Docker Compose

Зависимости направлены снаружи внутрь

01

Presentation

aiogram-роутеры, хендлеры команд, форматтеры карточек матчей

Запрещено: SQL-запросы, вызовы API КХЛ, бизнес-правила

02

Service

Выборки матчей, подписки, идемпотентность уведомлений

Запрещено: импорт aiogram, форматирование сообщений, прямой SQL

03

Repository

SQLAlchemy 2.x, сессии и транзакции, миграции Alembic

Запрещено: сетевые запросы, знание о Telegram, решения об отправке

04

Infrastructure

Адаптер API КХЛ на httpx, планировщик APScheduler, конфигурация

Запрещено: бизнес-логика, тексты сообщений, «сырые» ответы API наружу
